📍 ACCESS POINTS

1. WEB INTERFACE
   URL: http://localhost:5000
   Features:
   - Voice input/output
   - Text questions
   - Conversation history
   - Real-time status

2. API ENDPOINTS
   
   a) Ask Question
      POST /api/ask
      Payload: {"question": "Your question"}
      Response: JSON with answer
   
   b) Internal Webhook
      POST /api/webhook
      Payload: {"question": "Your question"}
      Response: JSON from webhook or Google
   
   c) External Webhook
      POST /webhook/<webhook_id>
      Params: question, user, etc.
      Response: JSON formatted response
   
   d) Get Status
      GET /api/status
      Response: Agent status & statistics
   
   e) Get History
      GET /api/history
      Response: All conversations
   
   f) Clear History
      POST /api/clear-history
      Response: Confirmation

3. N8N INTEGRATION
   - Import provided n8n-huvoice-workflow.json
   - Create HTTP Request node to /api/webhook
   - Process responses in n8n
